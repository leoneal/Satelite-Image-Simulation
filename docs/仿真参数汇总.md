## 卫星模型

### 简易几何体模型（手搭，当前 segA/B/C 使用）

通过 Blender Cube/Cylinder 搭建，每个部件为独立 mesh 对象，scale=1.0（无渲染 bug）。

| 部件名 | 几何体 | 尺寸 (m) | 局部位置 (m) | pass_index | cat_id |
|--------|--------|----------|-------------|-----------|--------|
| body | Cube | 4.0×2.0×1.5 | (0, 0, 0) | 1 | 1 |
| panel_1 | Cube | 4.0×1.0×0.04 | (-3.0, 0, 0.1) | 2 | 2 |
| panel_2 | Cube | 4.0×1.0×0.04 | (3.0, 0, 0.1) | 3 | 2 |
| antenna_phased_1 | Cylinder | r=0.4, h=0.3 | (0, 0, 1.0) | 100 | 3 |
| antenna_reflector_1 | Cylinder | r=0.3, h=0.8 | (0, 0, -1.0) | 150 | 4 |

| 属性 | 值 |
|------|-----|
| 总尺寸 | ~10.0×2.0×2.7 m |
| 材质 | Emission (strength=10) + Principled BSDF，fac=1.0（100% emission） |
| 创建方式 | `_build_simple_model()` → `size=X` + `transform_apply(scale=True)` → scale=1.0 |
| 部件颜色 | body 灰 (0.7,0.7,0.7) / panel 蓝 (0.1,0.2,0.5) / phased 金 (0.95,0.95,0.8) / reflector 银 (0.85,0.85,0.9) |

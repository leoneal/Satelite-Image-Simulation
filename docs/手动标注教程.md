# 卫星模型手动标注教程（v2.0）

## 目标

为每颗卫星指定 **5 类部件**，用于实例分割标注：

| # | 类别 | 说明 | 命名关键词 |
|---|------|------|-----------|
| 1 | body | 卫星本体 | 名称以 `body` 开头 |
| 2 | solar_panel | 太阳翼板 | 名称含 `panel` 或 `solar` |
| 3 | phased_array_antenna | 相控阵天线 | 名称含 `phased` 或 `array` |
| 4 | reflector_antenna | 反射面天线（碟形） | 名称含 `reflector` 或 `dish` |
| 5 | solar_panel_tripod | 太阳翼支架 | 名称含 `tripod` 或 `truss` |

> **不需要手动切分左右翼**——脚本会自动检测跨中心的翼板 mesh 并切成左右两个实例。
> **不需要重命名太阳翼为 panel_1/panel_2**——脚本自动编号。但同一颗卫星若有多个独立翼板组，需手动分开（见下）。

## 操作步骤（Blender GUI）

### 1. 导入 FBX

```
File → Import → FBX → 选择 data/sat_models/fbx/<类别>/<卫星>/<卫星>.fbx
```

导入后 Outliner（右上角列表）会显示模型的所有 mesh。**先对照模型目录里的 `彩图/` 参考图片**，搞清楚每个部件是什么。

### 2. 识别部件类别

在 Outliner 中逐个看 mesh 名字。典型情况：

- `Solar panel _front` / `Solar panel _back` → 太阳翼（脚本自动识别，不用动）
- `Gold-plating`、`Aluminizing`、`White paint`、`parts` → 本体包覆/蒙皮 → 归为 body
- `Cylinder*`、`Rectangle*`、`Sphere*` 等 → 可能是天线/支架，对照彩图判断

### 3. 需要拆分时（一个 mesh 混了多类部件）

例如一个 mesh 里既有本体又有天线：

1. 在 Outliner 选中该 mesh（或视口中点击）
2. 按 `Tab` 进入编辑模式
3. 用鼠标框选（`B`）或循环选择（`Alt+点击`）选中属于天线的面
4. 按 `P` → **Selection**（分离选中面为新物体）
5. 按 `Tab` 退出编辑模式
6. 在 Outliner 中双击新物体重命名

**技巧：** 连续的面可以用 `L`（hover 后按 L 选择相连面）、`Ctrl+L`（选择相连的面岛）快速选中。

### 4. 重命名（关键——脚本按名字识别类别）

在 Outliner 中 `F2` 重命名，规则：

| 部件 | 命名示例 |
|------|---------|
| 本体（多个 mesh 没关系，都行） | `body`、`body2`、或保留原名（Gold-plating 等自动归 body） |
| 相控阵天线 | `antenna_phased_1` |
| 反射面天线 | `antenna_reflector_1` |
| 太阳翼支架 | `tripod_1` |
| 太阳翼（多组独立翼板时） | `panel_1`、`panel_2`（**不同组用不同编号**） |

**注意：**
- 脚本判断规则：名称含 `phased` → 相控阵；含 `reflector`/`dish` → 反射面；含 `tripod`/`truss` → 支架；以 `panel` 开头或含 `solar` → 太阳翼；其余 → body
- 同一个物理翼板的 front/back 面（正反面 mesh）脚本自动归为同一实例，无需处理
- 数字开头的对象名（如 `1323_00`）会被当作"完整模型"用于 beauty 渲染——**新模型不需要这个**，不要用数字开头命名

### 5. 保存

```
File → Save As → 保存到 output/blend_files/ 下
```

**文件命名约定**（与原始模型分类编号一致，便于 134 颗全量管理）：

| 类别 | 前缀 | 示例 |
|------|------|------|
| 导航卫星 | NavSat | `NavSat_1_Beidou-GEO.blend` |
| 光学遥感卫星 | OptSat | `OptSat_41_sbirs-high.blend` |
| 微波遥感卫星 | MicSat | `MicSat_12_terraSAR.blend` |
| 通信卫星 | ComSat | `ComSat_42-tdrs.blend` |

编号 = 该卫星在原模型目录中的编号（`导航_1_Beidou-GEO` → `NavSat_1_Beidou-GEO`）。
渲染循环自动检测 `output/blend_files/<此命名>.blend`。

### 6. 渲染

管线新增 `--blend_path` 参数：

```powershell
& "E:\Blender\blender.exe" -b -P "blender\render_scene.py" -- `
  --ephem_dir "dataset/segB_v2/ephemeris" `
  --output_root "dataset/v2.0/NavSat_1_Beidou-GEO" `
  --start 172020 --end 172574 --stride 277 `
  --blend_path "output/blend_files/NavSat_1_Beidou-GEO.blend" `
  --fbx_path "data/sat_models/fbx/导航卫星/导航_1_Beidou-GEO/1_Beidou-GEO_model.fbx" `
  --model_scale 0.067 --sat_class_id 5 `
  --frame_variations 5 --attitude_jitter_deg 90 `
  --sun_phase_offsets "60,120" `
  --tag "lt70km"
```

`--fbx_path` 用于定位纹理目录（.blend 中不保存纹理）。

## 与原 DSP.blend 流程的区别

| | DSP.blend（旧） | 新模型（v2.0） |
|---|---|---|
| 模型来源 | 手动分离面 + 完整模型 | 3ds Max FBX 自带部件分离 |
| 需要做的 | 分离每个部件 | 只分离**混在一起的天线/支架**，重命名即可 |
| 完整模型 | 需要（1323_00） | 不需要 |
| 纹理 | 纯色 | 自动匹配 FBX 目录纹理 |

## 建议顺序

先标 Beidou（部件少，6 个 mesh），标完跑一张验证渲染，确认流程无误后再逐颗处理其余 9 颗。

## 一、数据集概况

本数据集为**空间交会工况卫星成像仿真数据集**：以观察卫星第一视角对目标卫星进行连续成像仿真，每张图像附带**检测、实例分割、位姿和成像条件**四类标注，用于空间目标感知算法（目标检测、实例分割、位姿估计）的训练与验证。

### 1.1 版本一览

| 版本 | 卫星数 | 图像数 | 图像类型 | 光照 | 路径 |
|------|--------|--------|----------|------|------|
| v2.0 | 13 | 40,950 | 彩色 | 60-200（相对强度） | `E:/sat_dataset/v2.0/` |
| **v2.1（当前）** | **14** | **44,100** | **灰度图** | **太阳常数物理光照** | `E:/sat_dataset/v2.1/` |

### 1.2 成像场景

| 参数 | 值 |
|------|-----|
| 工况 | 双星交会（观察星 → 目标星），200 Hz 高精度星历 |
| 成像距离 | 47.7 – 250 km（远距目标 30-100 px，近距约 200 px） |
| 图像分辨率 | 2048×2048，8-bit PNG |
| 相机 | 追踪模式，视场角 0.08° |
| 每帧变体 | 50 个（5 姿态 × 10 光照角度） |

## 二、目录结构与文件命名

```
E:/sat_dataset/v2.1/
└── NavSat_1_Beidou-GEO/            # 14 颗卫星各一个目录
    ├── images/
    │   ├── lt70km/                 # 近距离段：42 帧 × 50 变体 = 2,100 张
    │   ├── 70_250km_0/             # 远距离前段：11 帧 × 50 = 550 张
    │   └── 70_250km_1/             # 远距离后段：10 帧 × 50 = 500 张
    └── annotations/
        ├── instance_masks/{段名}/  # 实例分割掩码（与图像同名 PNG）
        ├── yolo/{段名}/            # YOLO 标签（与图像同名 txt）
        ├── pose/{段名}/            # 位姿真值（与图像同名 txt）
        ├── factors_*.csv           # 影响因素（每子批次一个 CSV）
        ├── coco_detection_*.json   # COCO 检测标注（每子批次）
        ├── coco_segmentation_*.json# COCO 分割标注（RLE 编码）
        └── splits.json             # train/val 划分
```

**文件命名规则：**

| 文件名 | 含义 |
|--------|------|
| `frame_172020.png` | 帧 172020 的**原始变体**（姿态 0 + 真实光照角度） |
| `frame_172020_v001.png` | 同帧的第 1 个扩增变体（v001-v049 共 49 个） |

- `frame_id`（172020 等）= 星历帧号，帧号越大距离越近（本工况中 172020≈70 km，181190≈47.7 km）
- 变体号 v001-v049 = 50 组合中的后 49 个：`v = 姿态编号×10 + 光照编号`（光照编号 0 = 真实角度，1-9 = 随机角度）

## 三、标注体系

### 3.1 类别体系（YOLO class id）

| 范围 | 含义 |
|------|------|
| 0 | body 卫星本体 |
| 1 | solar_panel 太阳翼板 |
| 2 | phased_array_antenna 相控阵天线 |
| 3 | reflector_antenna 反射面天线 |
| 4 | solar_panel_tripod 太阳翼支架 |
| 5-18 | **卫星型号**（整星 bbox，见 1.3 表） |
| 19-22 | **卫星类别**（19=导航 / 20=光学遥感 / 21=微波遥感 / 22=通信） |

> 每张图的 YOLO 标签中：**第 1 行 = 卫星类别，第 2 行 = 卫星型号，其余 = 部件**（部件可能因遮挡/视角缺少数个）。

### 3.2 标注格式详解

**① YOLO 检测**（`annotations/yolo/<段>/frame_*.txt`）

每行一个目标，归一化坐标：
```
class_id  x_center  y_center  width  height
```
示例（thuraya 某帧）：
```
22 0.5032 0.4956 0.0396 0.0137     ← 卫星类别（通信）
18 0.5032 0.4956 0.0396 0.0137     ← 卫星型号（thuraya）
0  0.5029 0.4939 0.0039 0.0054     ← body
1  0.4927 0.4919 0.0186 0.0063     ← 太阳翼
...
```

**② COCO 检测/分割**（`annotations/coco_detection_*.json` / `coco_segmentation_*.json`）

标准 COCO 格式，categories 为 5 类部件（id 1-5）。分割 JSON 含 RLE 编码（`segmentation` 字段，column-major run-length）。

**③ 实例分割掩码**（`annotations/instance_masks/<段>/frame_*.png`）

8-bit 灰度 PNG，与图像同尺寸。**像素值 = 实例编号 × 50**：

| 像素值 | 含义 |
|--------|------|
| 0 | 背景（纯黑） |
| 50 | body（实例 1） |
| 100, 150, 200, 250 | 太阳翼实例 2-5 |
| 250 | 所有编号 ≥5 的部件（相控阵/反射面/支架）——**封顶值** |

> ⚠️ **重要**：PNG 中编号 ≥5 的部件全部显示为 250，**从 PNG 无法区分部件类别**。需要类别信息请用 COCO JSON（PNG 仅用于可视化/重建检测框）。

**④ 位姿真值**（`annotations/pose/<段>/frame_*.txt`）

单行 7 个数：
```
qx qy qz qw rx ry rz
```
- 四元数（qx,qy,qz,qw）：目标卫星 ECI 姿态（**已包含扩增姿态扰动**）
- 相对位置（rx,ry,rz）：目标相对观察星位置，单位米，ECI(J2000) 坐标系

**⑤ 影响因素**（`annotations/factors_*.csv`）

每行一张图，记录成像条件：

| 列 | 含义 |
|----|------|
| filename | 图像文件名 |
| frame_id | 星历帧号 |
| variation | 变体号（0 = 原始变体） |
| distance_km | 两星相对距离（km） |
| sun_phase_angle_deg | 实际光照角度（相机-目标连线与太阳方向夹角） |
| sun_irradiance_w_m2 | 太阳辐照度（W/m²，物理量纲；基线 1361 = 太阳常数） |
| fov_deg | 相机视场角（0.080°） |

> 光照角度物理含义：**0° = 背光**（太阳在相机后方，目标朝向相机一面在阴影中）、**180° = 顺光**（太阳在目标后方，目标受光面正对相机）。45°-135° 为侧光。

### 3.3 数据集划分

- `splits.json`：每 5 帧取 1 帧为验证集（按渲染批次生成）
- 建议按帧号划分 train/val 而非随机划分——相邻帧高度相似，随机划分会导致数据泄漏

## 四、使用方法

### 4.1 读取图像与 YOLO 标签

```python
import os
import numpy as np
from PIL import Image

sat = 'NavSat_1_Beidou-GEO'
img_dir = f'E:/sat_dataset/v2.1/{sat}/images/lt70km'
yolo_dir = f'E:/sat_dataset/v2.1/{sat}/annotations/yolo/lt70km'

fname = 'frame_181190.png'  # 最近距离帧的原始变体
img = np.array(Image.open(os.path.join(img_dir, fname)))  # (2048, 2048) 灰度
labels = np.loadtxt(os.path.join(yolo_dir, fname.replace('.png', '.txt')))
cls, xc, yc, w, h = labels[:, 0], labels[:, 1], labels[:, 2], labels[:, 3], labels[:, 4]
```

### 4.2 读取 COCO 标注

```python
import json

seg_path = f'E:/sat_dataset/v2.1/{sat}/annotations/coco_segmentation_*.json'
# 每个子批次一个 JSON（文件名含帧范围）；多个 JSON 需合并 images/annotations 列表
with open(sorted(__import__('glob').glob(seg_path))[0]) as f:
    coco = json.load(f)
print(coco['categories'])          # [{id:1, name:'body'}, ...]
print(coco['images'][0])           # {id, file_name, width, height}
print(coco['annotations'][0])      # {bbox, area, segmentation(RLE), category_id}
```

> COCO 的 image id = `frame_id × 1000 + 变体号`（与文件名的对应关系由 file_name 字段给出）。

### 4.3 读取实例分割掩码

```python
mask = np.array(Image.open(f'E:/sat_dataset/v2.1/{sat}/annotations/instance_masks/lt70km/{fname}'))
instance_id = mask // 50   # 解码实例编号（0=背景，1=body，2-5=太阳翼，其余=250//50=5）
```

### 4.4 读取位姿与影响因素

```python
pose = np.loadtxt(f'E:/sat_dataset/v2.1/{sat}/annotations/pose/lt70km/{fname.replace(".png", ".txt")}')
qx, qy, qz, qw, rx, ry, rz = pose

import pandas as pd
factors = pd.concat([pd.read_csv(fp) for fp in
                     __import__('glob').glob(f'E:/sat_dataset/v2.1/{sat}/annotations/factors_*.csv')])
factors = factors.set_index('filename')   # 按文件名查表
print(factors.loc['frame_181190.png'])    # 该图的距离/角度/辐照度/FOV
```

### 4.5 训练任务建议

| 任务 | 数据用法 |
|------|----------|
| **目标检测** | YOLO 标签直接可用；若用 COCO 生态，用 coco_detection_*.json。类别可按需裁剪（仅用 5-18 型号类做型号识别、19-22 做类别识别、0-4 做部件检测） |
| **实例分割** | 用 coco_segmentation_*.json（RLE 可直接喂 mmdetection/detectron2）；掩码 PNG 用于可视化或数据检查 |
| **位姿估计** | 图像 + pose txt（四元数 + 相对位置）。注意姿态已含扩增扰动，标签与图像严格一致 |
| **条件分析** | factors CSV 按 distance_km / sun_phase_angle_deg / sun_irradiance_w_m2 分组统计，可做条件分布分析、难例挖掘 |

**多卫星联合训练**：各卫星目录互相独立、类别体系统一（型号类 5-18 全局唯一），直接合并多颗卫星的数据即可。注意同一帧号在不同卫星目录中是**同一个场景**（仅目标模型不同），划分 train/val 时建议按帧号全局一致划分，避免同帧跨星泄漏。

## 五、注意事项

1. **掩码 PNG 的类别信息不完整**：编号 ≥5 的部件在 PNG 中全部封顶为 250，类别区分请查 COCO JSON
2. **灰度图三通道相同**：RGB 通道值一致，按单通道读取即可
3. **相邻帧高度相似**：200 Hz 星历下相邻帧目标变化极小；50 个变体是同帧的姿态/光照扩增，train/val 划分务必按帧号而非随机
4. **DSP 卫星为纯色模型**：无纹理，部件为纯色材质
5. **v2.0 与 v2.1 的差异**：v2.0 为彩色图、无卫星类别标签（YOLO 仅部件+型号）、光照强度无物理标定、3 光照角度变体、factors 列名为 `sun_energy`。两版本不建议混合训练
6. **坐标系统**：位姿为 ECI(J2000) 右手系，Z 轴向上
7. **图像亮度**：灰度值范围约 0-255，暗部（背光）卫星像素约 40-60，亮部（顺光）约 190-220，个别镜面高光可达 255（属正常现象）

# 卫星图像仿真数据集扩充工作报告

> 版本：v1.1 | 日期：2026-08-06 | 基于 Phase 1-5 开发成果

---

## 1. 概述

本阶段工作的核心目标是将卫星图像仿真数据集从最初的 500 帧扩充至 20,000+ 帧规模，以满足空间目标检测与分割算法的训练需求。数据集按算法类型分为两类：远距离点目标检测数据集（数据集 A）和近距离目标检测与实例分割数据集（数据集 B）。

技术路线分为五个阶段：渲染时姿态扩增、光照条件变化、新轨道工况（待数据）、分析式点目标生成、数据集打包交付。

---

## 2. Phase 1：渲染时姿态扩增

### 原理

在 Blender 渲染阶段，对目标卫星施加随机姿态扰动。每帧原始图像额外渲染 N 个变体，每个变体的卫星绕随机三维轴旋转一个随机角度（均匀锥形分布）。这种方法无需修改 MATLAB/STK 星历数据，直接在渲染端完成，能有效增加不同视角的样本数量。

### 参数配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--frame_variations` | 1 | 每帧渲染的变体数量 |
| `--attitude_jitter_deg` | 0 | 最大随机扰动角度（度） |

### 使用示例

```powershell
blender -b -P render_scene.py -- \
  --frame_variations 20 --attitude_jitter_deg 90 \
  ... (其他参数)
```

每帧生成 20 个姿态变体，扰动范围 ±90°，444 帧原始数据可扩展为 8,880 张。

---

## 3. Phase 2：光照条件变化

### 原理

在渲染端旋转太阳方向，模拟不同的太阳-目标-相机相位角，产生顺光、侧光、逆光等不同光照条件。太阳方向绕相机-目标-太阳平面的法向量旋转，最大化光照变化幅度。

同时将卫星材质从原先的 85% 自发光 + 15% BSDF 改为 **95% BSDF + 5% 自发光**，使卫星外观接近真实太空光照物理——受光面明亮、背光面阴暗，阴影随太阳角度变化。

### 参数配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--sun_phase_offsets` | 空 | 逗号分隔的太阳相位偏移角度，如 `"45,90,135,180"` |
| `--sun_energy_range` | 空 | 太阳能量随机范围，如 `"100,300"` |

### 使用示例

```powershell
blender -b -P render_scene.py -- \
  --frame_variations 10 --attitude_jitter_deg 90 \
  --sun_phase_offsets "60,120,180" \
  ... (其他参数)
```

### 与姿态扩增的叠加

姿态变体与光照变体可以联合使用：每帧渲染姿态变体 × 光照变体 = 组合数量。例如 10 姿态 × 3 光照 = 30 个组合/帧，444 帧可产生 13,320 张图像。

## 4. Phase 3：新轨道工况（待数据）

### 原理

使用不同的轨道初始条件（太阳相位角、相对速度、轨道倾角等）通过 MATLAB/STK 生成多组星历数据，每组对应一个独立工况。每个工况产出约 500 帧，叠加姿态/光照扩增后可进一步扩大。

### 状态

本阶段需要新的轨道工况数据输入，目前已具备渲染管线的全部扩增能力，数据就绪后可直接投产。

## 5. Phase 4：分析式点目标生成器

### 原理

对于远距离段（目标 < 5 像素），采用纯分析方法生成点目标图像，不依赖 Blender 渲染。方法包括：

1. **相机投影**：从 ECI 星历数据计算目标在图像平面的亚像素坐标（与 render_scene.py 使用相同的相机模型）
2. **高斯 PSF 合成**：以 σ=1.2 的高斯点扩散函数模拟光学系统对点源的模糊效果，形成 2-3 像素的可见斑点
3. **恒星星场**：幂律分布生成 10,000 颗随机恒星背景，模拟真实星空
4. **传感器噪声**：高斯噪声 σ=3.0 模拟探测器读出噪声

生成速度约 1,000 帧/秒（vs Blender 渲染的 17 秒/帧），适合快速量产大规模点目标数据集。

### 参数配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--fov` | 14.0 | 相机视场角（度） |
| `--camera_mode` | stare | 相机模式（track/stare） |
| `--psf_sigma` | 0.7 | 点目标高斯 PSF 标准差 |
| `--bg_noise_std` | 3.0 | 背景噪声标准差 |
| `--resolution` | 2048 | 图像分辨率 |
| `--start/--end/--stride` | 0/all/1 | 帧范围与间隔 |

### 使用示例

```bash
python tools/point_target_generator.py \
  --ephem_dir output/ephemeris \
  --output_dir output/dataset_point \
  --tag "batch_001" \
  --start 22482 --end 23166 --stride 25 \
  --fov 14 --camera_mode stare --resolution 2048
```

## 6. Phase 5：数据集打包

### 原理

将分散在各个渲染批次目录中的图像和标注整合为统一的数据集格式。采用索引模式（文件保留在原位置，仅生成索引文件和标注汇总），避免大量复制。

### 两种数据集

**数据集 A（远距离点目标检测）**：
- 来源：分析式点目标生成器 + segA/segC Blender 渲染图
- 输出：`labels.csv`（亚像素坐标 + 亮度 + 距离）+ `manifest.json`（文件索引）+ `splits.json`（训练/验证划分）
- 标注格式：浮点亚像素坐标，适用于点目标检测算法

**数据集 B（近距离检测/分割/位姿）**：
- 来源：segB Blender 渲染图（含姿态/光照扩增）
- 输出：`instances.json`（COCO 格式，含 bbox + RLE 分割）+ `manifest.json` + `splits.json`
- 标注格式：5 类实例分割（卫星本体、太阳翼、相控阵天线、反射面天线、太阳翼支架）

### 使用示例

```bash
# 数据集 A
python tools/dataset_builder.py --mode point \
  --source "output/dataset_point/batch1,output/images/segA_DSP_..." \
  --output output/dataset_point/v1

# 数据集 B
python tools/dataset_builder.py --mode close \
  --source "output/images/segB_DSP_full_...,output/images/segB_Simple_..." \
  --output output/dataset_close/v1
```

## 7. 数据集产量估算

| 扩增手段 | 乘数 | 说明 |
|----------|------|------|
| segB 原始帧 | ×1 | 444 帧（单工况） |
| 姿态扩增 | ×20 | 每帧 20 个随机朝向 |
| 光照变化 | ×4 | 4 种太阳相位（原始 + 3 偏移） |
| 多工况 | ×N | N 组轨道数据 |
| 点目标生成 | 独立 | 10,000+ 帧（分析式） |

**第一阶段目标**：数据集 A ≥ 10,000 帧 + 数据集 B ≥ 10,000 帧 = 20,000+ 帧。
